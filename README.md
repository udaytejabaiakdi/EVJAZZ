# ABHI EV MOTORS & EV JAZZ — Pure White Minimalist Electric Two-Wheeler Website

A neat, clean, minimalistic, and modern showcase portal built for **ABHI EV MOTORS** & **EV JAZZ Mobility Solutions**, Kukatpally & IDA Nacharam, Hyderabad.

Inspired by **Ather Energy's pure white design aesthetic**, featuring seamless fluid vehicle cutouts, interactive model switcher tabs, instant EMI calculation, fuel savings metrics, and direct WhatsApp test ride booking.

---

## 🚀 How to Run the Website

### Option 1: Direct Double-Click (Zero Setup)
Simply double-click [`index.html`](file:///c:/Users/baika/Downloads/EV%20jazz/index.html) in Windows File Explorer. All fonts, styles, logic, and high-resolution white studio cutouts are completely local and run offline with zero external dependencies.

### Option 2: One-Click Local Server Launcher
Double-click [`start_website.bat`](file:///c:/Users/baika/Downloads/EV%20jazz/start_website.bat) to launch an instant local server on `http://localhost:8080` and open your browser automatically.
